## Usage

1. Download all files and put them in a folder.
2. Run `1.Add-to-desktop-right-click.bat`.
3. Enjoy your new desktop context menu!

## More detail
### Disabling 'NVIDIA Display Container LS'
The 'NVIDIA Display Container LS' service uses a decent amount of CPU usage in the background for Logging/Telemetry, so it is best to disable the service from running constantly in the background when you do not even use it.
For convenience.
